# claude-setup-kit

A Claude Code power setup, packaged so another person's Claude can rebuild it:

- **whatsapp/**: Claude reads and sends WhatsApp, and a private WhatsApp group that drives Claude on your computer from your phone.
- **laptop-and-server/**: an old laptop as a 24/7 home server over Tailscale, port forwarding so localhost keeps working, moving live chats between machines, safety hooks.
- **terminals-and-board/**: a TUI board for running many Claude chats at once, session restore, status line, fat-chat reminders.
- **TIPS-FOR-CLAUDE.md**: the working rules that make it pleasant.
- **ALSO-AVAILABLE.md**: the rest of the setup, by name.

## How to use it

Open Claude Code and tell it:

> Clone https://github.com/eitanf1336/claude-setup-kit and read START-HERE-CLAUDE.md, then set this up for me step by step.

Everything is untested outside the original machine. Your Claude should read each script before running it.
